# Movie Project

This project is a React + Vite app for a movie website starter. It is built to help you learn modern frontend development with reusable components, responsive styling, and a clean project structure.

## Features

- React app setup with Vite
- Fast local development server
- Responsive UI foundation
- Easy project structure for future movie pages and components

## Prerequisites

Before running the project, make sure you have:

- Node.js installed
- npm installed
- Visual Studio Code (recommended)
- Windows Command Prompt (CMD) or PowerShell

## Run the Project in CMD

Open Command Prompt and go to the project folder:

```cmd
cd C:\Users\Dell\Desktop\movie
```

Then install dependencies:

```cmd
npm install
```

Start the local development server:

```cmd
npm run dev
```

After that, open the URL shown in the terminal, usually:

```text
http://localhost:5173/
```

> If you are in Windows CMD, using `npm` is usually fine. You can also use `npm.cmd` if needed.

## Build for Production

To create a production build:

```cmd
npm run build
```

To run lint checks:

```cmd
npm run lint
```
